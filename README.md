## About

How to add a global dark mode in your Laravel project with Tailwind CSS.

<br>

## Installation

0. Checkout branch

```bash
git clone https://github.com/capsulescodes/articles.git

cd articles

git checkout 004-add-a-global-dark-mode-with-tailwindcss
```

<br>

1. Install dependencies

```bash
composer install

npm install
```

<br>

2. Add environment and generate application key

```bash
cp .env.example .env

php artisan key:generate
```

<br>

3. Run development server script

```bash
npm run dev
```

<br>

4. Link your project

```bash
herd link article
```

<br>

5. Visit your website : http://article.test
